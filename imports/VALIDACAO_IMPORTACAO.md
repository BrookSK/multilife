## QUERIES SQL PARA VALIDAÇÃO RÁPIDA (rodar no phpMyAdmin ou terminal MySQL)

```sql
-- Contar pacientes importados hoje
SELECT COUNT(*) AS total_pacientes FROM patients
WHERE DATE(created_at) = '2026-08-14' AND deleted_at IS NULL;
-- Esperado: 48

-- Contar profissionais importados
SELECT COUNT(*) AS total_profissionais FROM users
WHERE email LIKE '%@import.multilife.local';
-- Esperado: ~54

-- Contar monitoramentos criados
SELECT COUNT(*) AS total_assignments FROM patient_assignments
WHERE DATE(created_at) = '2026-08-14';
-- Esperado: ~60

-- Verificar demands criadas
SELECT id, title, specialty, status FROM demands
WHERE description = 'Importado via planilha'
ORDER BY id;
-- Esperado: 22 demands

-- Verificar especialidades
SELECT id, name, status FROM specialties WHERE status = 'active' ORDER BY name;

-- Verificar se todos profissionais têm role 'profissional'
SELECT u.name, u.email, r.slug
FROM users u
JOIN user_roles ur ON ur.user_id = u.id
JOIN roles r ON r.id = ur.role_id
WHERE u.email LIKE '%@import.multilife.local'
ORDER BY u.name;

-- Verificar atribuições de um paciente específico (ex: EIKO)
SELECT pa.id, p.full_name, u.name AS profissional, pa.specialty,
       pa.session_frequency, pa.session_quantity, pa.status
FROM patient_assignments pa
JOIN patients p ON p.id = pa.patient_id
JOIN users u ON u.id = pa.professional_user_id
WHERE LOWER(p.full_name) LIKE '%eiko%'
ORDER BY pa.specialty;
```

## POSSÍVEIS PROBLEMAS

1. **Busca por nome dando erro 500**: já corrigido no código (placeholders duplicados no PDO) — confirme que o deploy mais recente está no servidor.

2. **Profissional duplicado**: se o cara da equipe rodou a migration mas já existia algum profissional com o mesmo nome, a query com `NOT EXISTS` evita duplicata. Mas se existia com nome ligeiramente diferente (com/sem acento), pode ter criado duplicata.

3. **Paciente sem vínculo no monitoramento**: se o INSERT do patient_assignment falhou (ex: paciente ou profissional não encontrado pela busca case-insensitive), o monitoramento pode estar faltando.

4. **Frequência/quantidade = 0 ou 1**: para linhas da planilha onde o TOTAL estava zerado, usamos 1 como valor mínimo.
